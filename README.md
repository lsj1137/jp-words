# 単語 — 일본어 단어 게임

JLPT N5·N4 단어 398개를 게임처럼 외우는 개인용 웹앱.
서버·빌드·설치 없이 `index.html`을 열면 끝.

## 기능

**4가지 모드**
- **4지선다 퀴즈** — 콤보 배수 + 시간 보너스로 점수 (`1~4` 키 지원)
- **타이핑** — 뜻 또는 읽기를 직접 입력. 일본어 IME 없이 로마자로 쳐도 자동 변환 (`toshokan` → `としょかん`)
- **플래시카드** — `Space`로 뒤집고 `←`/`→`로 모른다/안다
- **복습** — 간격 반복(Leitner). 오답은 10분 뒤, 정답마다 1일 → 3일 → 7일 → 16일 → 35일

**단어장** — 뜻·읽기·예문을 훑어보는 사전. 단어 398개 모두 예문 있음.
필터: N5 / N4 / 내 단어 / 아직 못 외움 / 틀린 적 있음

**학습 현황** — 최근 14일 학습량, 암기 단계 분포, 앞으로 7일 복습 예정, 레벨별 진행률, 자주 틀리는 단어

**그 외** — 다크/라이트 테마, 소리, 제한시간, 단어 직접 추가(CSV 일괄 붙여넣기 가능)

## 진도 저장

브라우저 localStorage에 자동 저장. 백업·기기 이동은 두 가지:

| 방법 | 담기는 것 |
|---|---|
| **📤 JSON 파일** (권장) | 진도 + 통계 + 일별 기록 + **내가 추가한 단어의 뜻까지** 전부. 불러올 때 `병합`/`덮어쓰기` 선택 |
| **🔗 진도 링크** | 진도만. 파일 없이 주소만 복사해서 옮김. `URL 자동저장`을 켜면 세션마다 주소창이 갱신됨 |

단어를 나중에 추가·삭제·재배치해도 예전 링크와 백업이 그대로 동작합니다 (순서가 아니라 단어 키 해시 기준).

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체. 이것만 열면 됨 |
| `words.js` | 단어 — `[표기, 읽기, 뜻, 레벨]` |
| `examples.js` | 예문 — `"표기": [일본어, 읽기, 한국어]` |

둘 다 메모장으로 고쳐도 되고, 없어도 앱은 돌아갑니다(예문만 안 보임).

## GitHub Pages로 배포

외부 라이브러리·API·빌드가 없는 정적 파일이라 그대로 올리면 됩니다.

```bash
git init && git add . && git commit -m "일본어 단어 게임"
git branch -M main
git remote add origin https://github.com/<아이디>/<저장소>.git
git push -u origin main
```

저장소 **Settings → Pages → Source: `Deploy from a branch` → `main` / `/ (root)`** 저장.
1~2분 뒤 `https://<아이디>.github.io/<저장소>/` 에서 열립니다.

- `file://`로 열 때보다 오히려 낫습니다 — HTTPS라 클립보드 API가 살아나서 `진도 링크` 복사가 확인창 없이 바로 됩니다
- 폰에서 그 주소를 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다
- 진도는 각자 브라우저의 localStorage에만 있으므로, 주소가 공개돼도 내 학습 기록이 남에게 보이지는 않습니다
- 무료 플랜은 저장소가 **public**이어야 Pages가 됩니다 (private은 유료)
